利用規約

第1条　はじめに

この規約は、井元 駿（以下「販売者」）が配布する「学会運営支援システム」（以下「本ソフト」）を使うときの約束ごとです。本ソフトを使い始めた時点で、この規約に同意したものとします。

「利用者」とは本ソフトを使う人、「ライセンス」とは購入した人に発行する名前入りのコード、「学会データ」とは利用者が本ソフトに入力した会員・大会・会費などの情報をいいます。

第2条　ライセンス

  1. 本ソフトは、購入しなくてもすべての機能を使えます。購入していないあいだは、画面に購入の案内が表示されます。
  2. 継続して使う場合は、ライセンスを購入してください。
  3. ライセンスは購入した個人1名のものです。学会や大学などの団体に与えるものではありません。
  4. 購入した本人が使うかぎり、パソコンの台数、担当する学会の数、年度に制限はありません。
  5. ライセンスに有効期限はありません。本ソフトを新しい版にしても、そのまま使えます。
  6. 年度の引き継ぎで、ライセンスは次の担当者に引き継がれません。次の担当者は、ご自身で購入してください。
  7. ライセンスを他人に譲ること、貸すこと、教えることはできません。

第3条　料金と返金

  1. ライセンスの料金は、販売ページに表示する金額です。支払いは1回だけで、毎年の料金はかかりません。
  2. 購入の前にすべての機能を無料で試せるため、購入したあとの返金は、原則としてしません。
  3. ただし、同じ人が間違えて2回以上購入した場合は、重なった分を返金します。
  4. 学会の経費として精算するかどうかは、利用者と学会のあいだで決めてください。販売者は、精算できることを約束しません。

第4条　データの扱い

  1. 学会データは、利用者のパソコンの中にだけ保存されます。販売者のサーバーに送られることはなく、販売者が見ることもできません。
  2. メールは、利用者が設定した利用者自身のメールアカウントから送られます。
  3. 学会データに含まれる個人情報は、利用者と学会の責任で管理してください。パソコンの管理、引き継ぎファイルの受け渡し、不要になったデータの削除も含みます。
  4. パソコンの故障などに備えて、引き継ぎファイルの書き出しなどで、定期的に利用者自身が控えを取ってください。
  5. 販売者が受け取る情報は、購入のときの氏名など販売サービスから届くものと、問い合わせの内容だけです。ライセンスの発行と問い合わせへの対応にだけ使います。

第5条　サポートと問い合わせ

  1. 問い合わせは、配布用のWebサイトの問い合わせ窓口だけで受け付けます。不具合の報告、使い方の質問、購入やライセンスについての連絡も、すべてこの窓口です。
  2. いただいた不具合の報告やご意見は、今後の改良の参考にします。ただし、返事をすること、修正すること、その時期は約束しません。
  3. 個別の機能の追加や変更、設定の代行、データの復旧の依頼には応じられません。使い方は、付属の「使い方説明書」をご覧ください。
  4. 問い合わせには、会員の氏名やメールアドレスなどの個人情報と、アプリパスワードを書かないでください。
  5. 本ソフトは、予告なく更新したり、配布を終了したりすることがあります。配布を終了したあとも、手元の本ソフトとライセンスはそのまま使えます。

第6条　禁止すること

  1. ライセンスのコードを他人に教える、公開する、売ること
  2. ライセンスを無効にしたり、偽のコードを作ったりすること
  3. 本ソフトを改造したもの、または本ソフトそのものを、販売者の許可なく配布したり売ったりすること
  4. 法律に反する目的で使うこと（本人の同意のない宣伝メールの一斉送信など）

改造していない本ソフトを、次の担当者や学会内の方に渡すことは自由です。ただし、ライセンスのコードは渡せません。

第7条　保証しないことと、責任の範囲

  1. 販売者は、本ソフトに不具合がないこと、利用者の目的に合うこと、すべてのパソコンやメールサービスで動くことを保証しません。
  2. メールの宛先や内容、印刷した名札や宛名の内容は、送る前・印刷する前に利用者が確かめてください。
  3. 本ソフトは、ドライブがBitLocker（デバイスの暗号化）で暗号化されたパソコンで使うことを前提とします。暗号化されていないパソコンで使ったことにより、パソコンの紛失や盗難などで学会データが漏れた場合、販売者は責任を負いません。
  4. 本ソフトの不具合によって利用者に損害が出た場合、販売者が負う責任は、その利用者が支払ったライセンスの料金を上限とします。購入していない利用者の場合も、同じ金額を上限とします。
  5. ただし、販売者の故意または重大な過失による損害には、前の項の上限を当てはめません。

第8条　ベータ版（試用版）について

  1. いま配布している本ソフトは、ベータ版（試用版）です。広く使っていただき、ご意見をいただくための版です。
  2. ベータ版のあいだは、料金はかかりません。正式版で料金をいただくようになるときは、配布用のWebサイトと本ソフトでお知らせします。
  3. ベータ版は、正式版よりも不具合が残っている可能性があります。引き継ぎファイルの書き出しで、こまめに控えを取ってください。
  4. ベータ版で入力したデータが正式版でもそのまま使えるよう努めますが、保証はしません。
  5. ベータ版の内容は、予告なく変更することがあります。

第9条　規約の変更と、適用する法律

  1. 販売者は、この規約を変更することがあります。変更した内容は、配布用のWebサイトと、本ソフトの次の版でお知らせします。
  2. 変更したあとも、すでに購入したライセンスはそのまま使えます。
  3. この規約には日本の法律を適用します。争いになった場合は、販売者の住所地を受け持つ地方裁判所を、最初に扱う裁判所とします。

附則：この規約は、2026年11月1日から適用します。
