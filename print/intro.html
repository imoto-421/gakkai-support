小さな学会の事務の道具

会員名簿・研究大会・年会費・案内メール・名札・年度の引き継ぎを、担当者のパソコン1台で管理する Windows のアプリです。

3,000円1回だけのお支払い・税込

パソコンの中だけ名簿を外に保存しません

全機能を無料で購入の前に、期限なく試せます

何ができるか

会員名簿

今ある Excel の名簿をそのまま取り込めます。会員種別は学会ごとに自由に決められ、宛名ラベルも印刷できます。

研究大会の受付

出欠、参加費・懇親会費などの料金と入金をまとめて管理。まだ払っていない人がひと目でわかります。

名札・受付一覧の印刷

名刺用紙に合わせた名札を PDF で作れます。お弁当や懇親会を申し込んだ人には色の印が付きます。

年会費

年度ごと・会員種別ごとに金額を決めて、納入と未納を管理。前の年度の未納もわかります。

案内メールの一括送信

ご自身の Gmail から、名前などを差し込んだメールを一斉に送れます。未納の方だけ、などの絞り込みもできます。

年度の引き継ぎ・複数の学会

次の担当者にはファイルを1つ渡すだけ。2つ以上の学会を担当していても、データは混ざりません。

名簿の扱い

会員の名前や住所は、担当者のパソコンの中だけに保存されます。開発者のサーバーはなく、開発者が名簿を見ることもできません。

送るのはメールだけ

インターネットに送るのは、案内メールの宛先・件名・本文だけ。担当者ご自身の Gmail から送ります。

パスワードは暗号化

Gmail のアプリパスワードは Windows の仕組みで暗号化して保存。引き継ぎファイルもパスワードで暗号化（AES-256）できます。

パソコンの管理は担当者で

ログインのパスワードや紛失への備えは、担当者の責任です。BitLocker（ドライブの暗号化）をおすすめしています。

向いている学会・向いていない学会

向いています

  • 会員が数十〜数百人で、事務の担当者が1人
  • 名簿を Excel で持っている
  • 担当者が Windows のパソコンと Gmail を使える
  • 事務の費用を、できるだけかけたくない

ほかの方法をおすすめします

  • 参加者が Web で申し込み、カードで払う形にしたい
  • 演題の登録や査読もシステムで行いたい
  • 何人かで同時に名簿を直したい
  • Mac しか使わない（いまは Windows 版だけ）

始めるまでの流れ

  1. 配布ページから zip ファイルをダウンロードし、右クリック →「すべて展開」
  2. 「GakkaiSupport.exe」をダブルクリック。青い画面が出たら「詳細情報」→「実行」（個人で作っているため。2回目からは出ません）
  3. 利用規約に同意して、学会名を入れる
  4. 今の Excel 名簿を取り込み、そのまま試す
  5. 続けて使うときは、配布ページから購入。3日以内に届くコードを「設定」に貼り付ける
